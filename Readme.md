# Credit Card Fraud Detection 🚀

A machine learning project to detect fraudulent credit card transactions using **Random Forest Classification**.  
The dataset contains **284,807 transactions**, with a highly imbalanced distribution between legitimate and fraudulent records.

---

## 📊 Dataset
- Source: [Kaggle Credit Card Fraud Dataset](https://www.kaggle.com/mlg-ulb/creditcardfraud)
- Records: **284,807 transactions**
- Fraudulent: **492**
- Legitimate: **284,315**
- Highly imbalanced dataset (1:577 ratio)

---

## 🔍 Exploratory Data Analysis (EDA)
- Automated EDA performed using **Pandas Profiling (Profile Report)**  
- Discovered patterns, correlations, and class imbalance  
- Visualizations for transaction distribution and fraud trends  

---

## ⚙️ Approach
1. Loaded and cleaned dataset with **Pandas & NumPy**  
2. Performed **EDA** with Pandas Profiling  
3. Balanced the dataset using **under-sampling**  
4. Split into training and testing sets  
5. Trained and optimized a **Random Forest Classifier**  
6. Evaluated using **Accuracy, Confusion Matrix, and Classification Report**  
7. Saved the trained model using **Pickle** for deployment
